# DDPM CCTV Basin-Centric Mockup

Mockup ที่ยึดโครงสร้างและภาษาภาพจาก `https://cctv.disaster.go.th/dashboard` แล้วปรับลำดับข้อมูลให้เหมาะกับผู้บริหารและทีมมอนิเตอร์ระบบ
ตัวอย่างระบบ `https://chayanrotp-ba.github.io/ddpm-cctv-monitoring-dashboard/`

## หน้าจอหลัก

- `index.html` — Dashboard ภาพรวมสถานการณ์รายลุ่มน้ำสำหรับผู้บริหาร
- `basin.html` — Drill-down ลุ่มน้ำ แสดงจังหวัด จุดวิกฤต และตารางสรุปสถานีรายลุ่มน้ำ
- `monitor.html` — เมนูสืบค้นข้อมูลและสถานะอุปกรณ์สำหรับเจ้าหน้าที่เทคนิค

ไฟล์ `login.html` และ `backoffice.html` เป็นหน้าตัวอย่างเดิมที่ยังเก็บไว้เป็นบริบทของระบบหลังบ้าน

## ฟังก์ชันสาธิต

- แสดงขอบเขตจริงของ 22 ลุ่มน้ำหลักทั่วประเทศไทยจากสำนักงานทรัพยากรน้ำแห่งชาติ
- กรองสถานการณ์ระดับเตรียมพร้อม อพยพ และต้องอพยพ
- ค้นหาและเลือกเฉพาะลุ่มน้ำ
- เปิดรายละเอียดลุ่มน้ำน่านและกล้อง CCTV แบบ Drawer
- แสดงสถานีและ Sensor น้ำท่า/ฝนที่เข้าเกณฑ์ในหน้ารายละเอียดลุ่มน้ำ
- แสดงเส้นทางน้ำธรรมชาติ DWR โดยกรองตามขอบเขตลุ่มน้ำ ONWR ที่เลือก
- แยกตารางสถานะอุปกรณ์ ข้อมูลระดับน้ำ ประวัติ และ Ranking ออกจาก Dashboard ผู้บริหาร
- ค้นหา/กรองอุปกรณ์และส่งออก CSV ตัวอย่าง
- Responsive สำหรับ Desktop, Tablet และ Mobile

เปิด `index.html` ได้โดยตรง ระบบจะใช้ ArcGIS Topographic basemap เมื่อเชื่อมต่อได้ และมีแผนที่แบบฝังเป็นตัวสำรองหากบริการภายนอกไม่พร้อม

> ข้อมูลชื่อสถานีและค่าระดับน้ำใน Mockup เป็นข้อมูลจำลองเพื่อยืนยันรูปแบบการนำเสนอ ไม่ใช่ข้อมูลเพื่อการตัดสินใจจริง

## แหล่งข้อมูลขอบเขตลุ่มน้ำ

- ชุดข้อมูล: [พื้นที่ 22 ลุ่มน้ำ ตามพระราชกฤษฎีกากำหนดลุ่มน้ำ](https://data.go.th/th/dataset/dataset_32_013)
- เจ้าของข้อมูล: สำนักงานทรัพยากรน้ำแห่งชาติ (สทนช.)
- Resource ID: `cabd0efd-73af-4652-bc4d-4add382078a5`
- ข้อมูลต้นทาง: Shapefile, WGS 1984 / UTM Zone 47N
- ไฟล์ใช้งานหน้าเว็บ: `data/onwr-basins-22.geojson` และ `data/onwr-basins-22.js`
- การแปลง: EPSG:4326 และลดความละเอียดเส้นขอบที่ 650 เมตรสำหรับการแสดงผลระดับประเทศใน Mockup

Catalog ระบุว่าเป็นข้อมูลสาธารณะและไม่มีเงื่อนไขการเข้าถึง แต่ไม่ได้ระบุชื่อสัญญาอนุญาต จึงควรตรวจสอบสิทธิ์กับ สทนช. อีกครั้งก่อนนำไปใช้ในระบบผลิต
